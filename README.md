# hse

Краткое описание проекта

Цель проекта: изучить и проанализировать набор данных опроса/анкеты, выявить ключевые факторы, провести факторный и корреляционный анализ, подготовить признаки и построить предиктивную модель для прогнозирования целевой переменной.

Набор данных: табличный CSV/Excel-файл с ответами респондентов (строки — наблюдения, столбцы — вопросы/переменные). Данные содержат числовые и категориальные признаки, возможны пропуски и шум.

Основные этапы исследования:
- импорт и первичный осмотр данных;
- очистка и обработка пропусков;
- кодирование категориальных признаков (ordinal/one-hot/ordinal encoder);
- корреляционный анализ и визуализация (heatmap, диаграммы распределения);
- факторный анализ (KMO, факторные нагрузки) и отбор признаков;
- построение модели (train/validation/test), оценка метрик и интерпретация результатов.

Использованные библиотеки:
- pandas, numpy — обработка данных;
- matplotlib, seaborn — визуализация;
- scikit-learn — предобработка, модели и метрики;
- factor_analyzer — факторный анализ, KMO;
- openpyxl — работа с Excel (при необходимости);
- дополнительно: scipy, statsmodels (по необходимости).

Файлы с анализом:
- основной ноутбук: [hse_project.ipynb](hse_project.ipynb)
- дополнительные версии: [hse_project-ver2.ipynb](hse_project-ver2.ipynb), [hse_project-ver3.ipynb](hse_project-ver3.ipynb)
