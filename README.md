# Анализ логов работы учащихся в цифровой среде

Учебно-исследовательский проект: анализ логов прохождения интерактивного
задания «Спектакль» — симуляции социальной сети, в которой респондент
создаёт сообщество, настраивает приватность и отвечает на письма, личные
сообщения и комментарии.

**Задача:** предсказать уровень цифровой грамотности (`GGlevel`, 4 уровня)
по логу действий и выяснить, какие действия его выдают.

## Данные

`education_hse_project/Спектакль_utf8_2.xlsx` — 2796 наблюдений, 39
содержательных признаков: время выполнения, число вызовов ассистента,
выбранные настройки сообщества, выбранные варианты ответов, а также
последовательности кликов.

## Метод

* **Предобработка.** Три кодировки пропуска (`NaN`, `'undefined'`, `'nun'`)
  сводятся к одной. Последовательности кликов, которые Excel исказил тремя
  способами (`'2,4,5'`, `2.4`, `Timestamp('2024-01-02')`), разбираются
  парсером и превращаются в длину и число повторов. Номинальные признаки
  кодируются one-hot. Ни одна строка не удаляется — пропуск информативен
  сам по себе и учитывается индикаторами.
* **Модель.** `GGlevel` — порядковая метка, поэтому решается задача
  классификации. Отбор модели по 5-fold кросс-валидации, отложенная
  выборка используется один раз. Все модели, включая базовые, меряются
  одним набором метрик: accuracy, macro-F1, взвешенная каппа, MAE в
  уровнях.
* **Латентная структура.** Классический факторный анализ применяется
  только к числовому блоку, где выполняются его предпосылки; для
  номинальных ответов используется множественный анализ соответствий
  (MCA) — корректный аналог для категориальных данных.

## Основные результаты

* Логистическая регрессия: **accuracy 0.55** против 0.33 у базовой модели,
  взвешенная каппа 0.67. Три разных семейства моделей упираются в
  0.52–0.55 — похоже, это потолок данного набора логов.
* **У 16 % респондентов лог не записан** — для них модель бессильна
  (accuracy 0.34 против 0.593 у остальных). Это технический сбой, а не
  поведение: с уровнем грамотности он не связан (p = 0.42).
* **Сильнейшие поведенческие маркеры** — проверка источников (ρ = 0.48) и
  нахождение верного адреса (ρ = 0.47). Время выполнения различает слабо
  (ρ = 0.07), причём сильные тратят на задание *больше* времени.
* **Содержательная компетентность измерима:** вторая ось MCA коррелирует
  с баллом на ρ ≈ 0.70, будучи построенной без обращения к нему. Её
  полюса — безопасные против небезопасных решений (не пересылать
  подозрительную ссылку, не публиковать телефоны).
* **Единого поведенческого фактора нет:** KMO числового блока 0.51, а
  выделенные факторы лишь группируют признаки одного происхождения.

Выводы целиком — в [CONCLUSIONS.md](education_hse_project/CONCLUSIONS.md),
разбор ошибок первых версий — в [REPORT.md](education_hse_project/REPORT.md).
